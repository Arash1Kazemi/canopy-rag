1. The Problem & Purpose

In Phase 2 baseline runs, planted problems failed as expected: when multiple copies or versions of a document existed (e.g., old vs. new bus fleet inventories), the model cited both or got confused by contradictions. Phase 5 solves this by introducing knowledge versioning, chunk life cycles, and duplicate/overlap detection.

2. Exact Code Structure & Files Added

Phase 5 modules live in rag_core/knowledge/:

  • rag_core/knowledge/changes.py — Computes structured change summaries between document versions (using Python's difflib).
  • rag_core/knowledge/lifecycle.py — Tracks chunk states across the pipeline: created ➔ embedded ➔ checked ➔ indexed.
  • rag_core/knowledge/duplicates.py — Detects exact matches (SHA-256 fingerprints), near-duplicates, and phrase overlaps.
  • scripts/duplicate_experiment.py — Measures duplicate behavior across parameter policies.

3. Deep Dive into Technical Mechanisms

A. Knowledge Versioning & Active Versions

When D10 version 2 is ingested, version 1 is retained in storage for audit trails, but only version 2 is marked active. Retrieval queries automatically filter out inactive versions.

B. Chunk Life Cycle (ChunkStage)

Chunks move through explicit states. A chunk is strictly prohibited from being retrieved unless its stage is indexed AND its parent version is active.

C. Three-Tier Duplicate Detection (Advice Only)

  • Exact: Same text fingerprint (skipped automatically at ingestion so duplicate files are never indexed twice).
  • Near Duplicate: High word-group similarity score (default threshold: 0.8).
  • Overlap: Shared contiguous phrase groups between distinct documents.

Crucial Rule: Duplicate and overlap detection produces advisory logs; human experts make the final decision.

4. How to Run Phase 5 (CLI Commands)

# Run ingestion with duplicate detection enabled
python -m rag_core ingest-case-study --detect-duplicates --run-id phase5-run

# Run the duplicate scan on an existing knowledge database
python -m rag_core find-duplicates --db results/ingestion/phase5-run/knowledge.sqlite
